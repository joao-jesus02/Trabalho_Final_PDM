# Mystic Creatures

Aplicativo Android desenvolvido para a disciplina de Programação para Dispositivos Móveis utilizando Java e Room Database.

## Funcionalidades

* Cadastro de usuários
* Login
* Recuperação de senha
* Cadastro de criaturas
* Atualização de criaturas
* Exclusão de criaturas
* Busca por criaturas
* Uso da câmera
* Fragmentos
* Sons
* Banco de dados Room

## Tecnologias Utilizadas

* Java
* Android Studio
* Room Database
* SQLite
* ViewBinding
* Fragments
* MediaPlayer
